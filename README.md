\# Projet Collecte



Ce projet permet de collecter et d'analyser des données avec Python.



\## Organisation

\- src/ : scripts Python

\- notebooks/ : exercices et analyses

\- data/ : fichiers de données

\- requirements.txt : dépendances Python



\## Objectif



Ce projet permet de découvrir les outils Python

pour la collecte et l'analyse des données.



\## Installation



Pour installer les bibliothèques nécessaires au projet :



python -m pip install -r requirements.txt
